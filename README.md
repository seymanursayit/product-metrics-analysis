# Product Metrics Analysis

## Project Overview

This project focuses on analyzing product metrics using Google Sheets. The goal is to evaluate game performance, understand user payment behavior, and identify potential areas for improvement.

## Objectives

- Calculate total revenue and the number of paying users.
- Measure conversion rate to paid users (CR to Paid).
- Calculate Average Revenue Per Paying User (ARPPU).
- Analyze the age distribution of paying users.
- Compare product performance across games.
- Develop hypotheses and recommendations based on the results.

## Tools & Skills

- Google Sheets
- Spreadsheet formulas and functions
- Product metrics analysis
- Conversion rate analysis
- Revenue analysis
- Data-driven decision-making

## Key Metrics

| Metric | Description |
|---|---|
| Total Revenue | Total revenue generated by each game |
| Paid Users Count | Number of users who made a payment |
| CR to Paid | Percentage of users who became paying users |
| ARPPU | Average revenue per paying user |
| Average Age | Average age of paying users |
| Median, Minimum & Maximum Age | Age distribution of paying users |

## Key Learnings

This project provided practical experience in calculating product metrics, comparing game performance, and using data to formulate hypotheses and business recommendations.
